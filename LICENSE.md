# Licences

The files under `imagery/` are derived from open satellite imagery. Each was cut out of a larger scene, in some cases stretched to 8 bits, and re-tiled in Web Mercator. Each keeps the licence of its source; there is no single licence for this repository's imagery. The licence and attribution of every file are in its `.json` sidecar and in [SOURCES.md](SOURCES.md).

| Source | Licence | What it asks |
| --- | --- | --- |
| Maxar Open Data Program | [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) | Attribution. **Non-commercial use only.** Say that the imagery was modified. |
| SpaceNet on AWS | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | Attribution. **Share alike:** the tiles here are themselves CC BY-SA 4.0, and so is anything made from them. |
| Satellogic EarthView | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | Attribution to Satellogic. |
| Umbra Open Data Program | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | Attribution. |
| Capella Space Open Data | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) | Attribution. |
